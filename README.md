> 💡 Um projeto simples e inteligente para calcular o consumo mensal de energia elétrica de aparelhos domésticos.

---

## 🚀 ✨ Funcionalidades

* 🔢 Cálculo automático de consumo mensal (kWh)
* 💰 Estimativa de custo de energia
* 🔁 Menu interativo no terminal
* ⚠️ Validação de entradas do usuário
* 📊 Resultados organizados e fáceis de entender

---

## 🧮 ⚡ Fórmula Utilizada

```id="6u9gfo"
consumo = (potência × horas/dia × 30) / 1000
```
